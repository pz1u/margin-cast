## 해석 한계

- 실험은 7일 단위 순차 배치여서 관측되지 않은 시기 요인과 완전히 분리되지 않는다.
- 세 메뉴의 탄력성 신뢰구간이 넓어 방향 판단보다 정밀한 수치 비교의 신뢰도가 낮다.
- Ground Truth 비교는 합성 데이터 생성 규칙 복원 여부만 평가하며 실제 매장 일반화를 보장하지 않는다.
