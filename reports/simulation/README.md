## 해석 한계

- 최근 관측 날씨를 시나리오 문맥으로 재사용했으며 실제 미래에는 예보가 필요하다.
- 1,000원 할인은 관측 실험과 같은 프로모션 노출 효과가 재현된다고 가정한다.
- 세트 구성은 신규 수요와 잠식 효과를 관측 데이터만으로 분리할 수 없어 이 비교에 포함하지 않았다.
- 수요 공통 변동과 원가 변동 폭은 실제 예측 오차로 보정되기 전까지 명시적 가정값이다.
