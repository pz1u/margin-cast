# 실험 피드백과 모델 보정 근거

MarginCast는 추천 전략을 실제로 적용한 뒤 시뮬레이션 당시 예측 분포와 관측 결과를 함께
저장한다. 이 기록은 예측 오차와 구간 보정 상태를 확인하기 위한 근거이며, 한두 건의 결과로
모델 계수를 자동 변경하지 않는다.

## 저장하는 값

- 실험 이름, 메뉴, 시작일·종료일
- 정가·할인액과 예측 기간
- 판매량·기여이익·기여이익 변화의 예측 평균과 80% 범위
- 실제 판매량과 기여이익
- 실제 개선폭을 계산할 기준 기간 또는 병행 대조군의 기여이익
- 기준선 산정 방식: `matched_period` 또는 `parallel_control`

실제 기간의 날짜 수와 예측 기간이 다르면 비교를 거부한다. 예측 평균이 80% 범위 안에
있어야 하며 NaN과 무한대는 저장하지 않는다. 기본 저장 위치는
`data/feedback/experiment_feedback.json`이고 생성 데이터와 마찬가지로 Git에서 제외된다.

## 평가 지표

각 기록은 판매량·기여이익·기여이익 변화에 대해 다음을 계산한다.

- 예측 오차와 절대 오차
- 실제 값이 0이 아닐 때의 절대 비율 오차
- 실제 값의 80% 예측 구간 포함 여부
- 이익 개선 방향의 예측 일치 여부

집계에서는 평균 오차, 평균 절대 오차, 평균 절대 비율 오차, 80% 구간 포함률과 이익 방향
정확도를 확인한다. 충분한 실험이 쌓였다면 80% 구간 포함률이 실제로 약 80%인지 보고,
일관된 편향이 있을 때 수요 분산이나 탄력성·원가 가정을 다시 추정한다.

`matched_period`는 과거의 비슷한 기간과 비교하므로 날씨·요일·추세 교란이 남는다.
가능하면 `parallel_control`을 사용하고, 어느 방식도 한 건의 결과를 인과효과의 확정값으로
취급하지 않는다.
