# MarginCast 웹사이트

`web/`은 매장 운영자가 가격·할인·세트 대안을 직접 입력하고 계산 결과를 비교하는
브라우저 웹사이트다. 별도 프론트엔드 프레임워크 없이 HTML, CSS, JavaScript로 구성하며
`src.http_api`가 정적 파일과 JSON API를 함께 제공한다.

## 실행

```powershell
.\.venv\Scripts\python.exe -m src.http_api
```

브라우저에서 `http://127.0.0.1:8000`에 접속한다.

## 화면 흐름

1. 가격·할인 또는 세트 구성을 선택한다.
2. 메뉴와 전략 값을 입력한다.
3. 필요하면 실제 단기예보 반영을 선택하고 매장 주소를 입력한다.
4. 기존 계산 엔진이 Monte Carlo 시뮬레이션을 실행한다.
5. 기대 기여이익 변화, 80% 예상 범위, 개선확률과 근거 신뢰도를 함께 확인한다.
6. Decision Engine의 `추천`, `소규모 실험`, `보류` 판단과 이유를 확인한다.
7. 실제로 실행할 전략은 `실험 피드백` 탭에서 예측 분포를 계획으로 저장한다.
8. 실험 종료 뒤 실제 판매량·기여이익과 기준선 이익을 입력해 누적 오차를 확인한다.

가격 화면은 현재 가격을 자동 기준으로 추가한다. 세트 화면은 Take Rate, 기존 동시구매 전환,
신규 수요와 다른 메뉴 잠식을 별도 가정으로 입력받는다. 관측되지 않은 세트 가정은 높은
개선확률과 별개로 `LOW` 신뢰도를 표시한다.

## 키와 브라우저 경계

웹사이트 JavaScript에는 기상청 키와 카카오 REST 키를 넣지 않는다. 두 키는 Python 서버의
`.env`에서만 읽는다. 현재 화면은 카카오 지도를 표시하지 않으므로 JavaScript 지도 키나
도메인 등록이 필요하지 않다. 실제 단기예보를 선택하면 입력한 주소는 로컬 서버를 거쳐
카카오 주소 검색 API로 전달되고, 반환된 좌표만 기상청 예보 조회에 사용한다.

## 현재 한계

- 합성 데이터로 학습한 데모 계산 결과다.
- 기본 가격 비교는 최근 관측 날씨 문맥을 사용하며, 실제 단기예보 비교는 현재 제공되는
  예보 범위 때문에 1~5일로 제한한다.
- 7일 전체의 같은 해상도 예보는 별도 중기예보 API 사용 권한과 해상도 결합 정책이 필요하다.
- 로그인, 매장별 데이터 저장과 공개 배포 설정은 포함하지 않았다.
- 실험 피드백은 현재 서버의 로컬 JSON 파일에 저장되며 사용자 계정 간 동기화는 지원하지 않는다.
- Agent 대화 화면은 사용자가 Agent 동작을 구현한 뒤 같은 API 위에 연결한다.
