MENU MANAGEMENT

메뉴와 원가

POS에서 가져온 메뉴의 식재료 원가를 확인하고 수정하면 원가율과 단품 기여이익을 자동으로 계산합니다. 수정한 원가는 전략 시뮬레이션의 기여이익에도 반영됩니다.

원가율 = 식재료 원가 ÷ 판매가 · 단품 기여이익 = 판매가 − 식재료 원가 − 수수료

내부 ID 메뉴 판매가 식재료 원가 원가율 단품 기여이익 분석 상태

판매가는 POS 값이라 이 화면에서 수정하지 않습니다. 단품 기여이익은 매장·배달 판매 비중과 수수료를 반영한 1개당 값입니다. 원가를 고친 뒤 Enter 또는 [저장]을 누르세요.
