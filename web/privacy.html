개인정보처리방침

초안이 문서는 현재 서비스 코드의 동작을 기준으로 작성한 초안입니다. 입력 필요로 표시된 항목은 운영자가 실제 정보를 채우고 법률 검토를 마친 뒤에 공개하세요.

시행일
입력 필요: 시행 날짜
개인정보처리자
입력 필요: 상호 또는 성명
개인정보 보호책임자
입력 필요: 이름, 직책, 이메일

1. 요약

MarginCast에는 회원가입과 로그인이 없습니다. 서비스 화면은 쿠키나 브라우저 저장소(localStorage 등)를 사용하지 않습니다. 이용자가 입력한 값 중 저장되는 것은 이용자가 직접 저장하는 실험 계획과 실제 결과 기록입니다.

2. 처리하는 정보

MarginCast가 처리하는 정보
정보사용 목적저장 여부
매장 주소 (실제 단기예보 반영을 선택한 경우) 주소를 좌표로 바꿔 기상청 단기예보를 조회 현재 코드에서는 실험 기록에 주소 원문을 저장하지 않습니다. 입력 필요: 배포 환경에서 재확인
가격, 할인, 세트 조건 등 시뮬레이션 입력값 계산 요청 처리 계산 후 별도로 저장하지 않습니다. 실험 계획으로 저장할 때는 선택한 전략의 정가와 할인액이 함께 저장됩니다.
실험 계획과 결과: 실험 이름, 메뉴, 시작일과 종료일, 예측 범위, 실제 판매량, 실제 기여이익, 기준선 기여이익 예측 오차, 예측 구간 포함률, 개선 방향 정확도 계산 서버의 JSON 파일에 저장합니다. 보관 기간: 입력 필요: 보관 기간
접속 기록 (IP 주소, 요청 시각 등) 보안과 장애 대응 MarginCast 서버는 요청 로그를 남기지 않도록 구성되어 있습니다. 공개 배포 시 호스팅과 프록시의 로그: 입력 필요: 수집 여부와 보관 기간

실험 이름 등 자유 입력란에는 이름, 연락처 같은 개인정보를 입력하지 마세요.

3. 외부 서비스로 전달되는 정보

외부 서비스로 전달되는 정보
받는 곳전달 정보목적
카카오 (로컬 주소 검색 API)이용자가 입력한 주소주소를 좌표로 변환
기상청 (단기예보 API)주소에서 변환한 좌표예보 조회

이 전달은 이용자가 "실제 단기예보 반영"을 선택하고 계산을 요청할 때만 일어납니다. 각 사업자의 보관과 이용 방식은 해당 사업자의 정책을 따릅니다. 처리 위탁과 제3자 제공의 법적 분류: 입력 필요: 법률 검토

4. 보관과 삭제

저장된 실험 기록의 보관 기간과 파기 시점: 입력 필요: 보관 기간과 파기 방법

현재 화면에는 저장된 기록을 삭제하는 기능이 없습니다. 삭제 요청을 받는 방법: 입력 필요: 삭제 요청 창구와 처리 기한

5. 이용자의 권리와 문의

열람, 정정, 삭제, 처리 정지를 요청하는 방법과 담당 부서: 입력 필요: 이메일 또는 연락처

6. 국외 이전

서버 호스팅 위치와 국외 이전 여부: 입력 필요: 호스팅 환경 확정 후 작성

7. 안전성 확보 조치

입력 필요: 배포 환경에서 실제로 적용한 접근 통제, 전송 구간 암호화, 저장 파일 보호 조치

8. 방침의 변경

변경 시 공지 방법과 이전 버전 보관: 입력 필요: 운영 정책
